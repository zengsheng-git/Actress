## 总结

判断有码/无码，核心看厂商的**发行渠道和注册地**。日本国内正规片商（如Moodyz、Kawaii、Attackers等）都需遵守日本刑法第175条，对敏感部位打码；而1pondo、bi-av、ラフォーレ ガール等则主要面向海外发行，无需打码。不过需要注意，网络上很多标称“无码”的资源可能是盗版解码或后期去码的伪无码，需结合画面实际内容判断。

问得好，直说：**不能 100% 确定，而且 project.md 那份分类确实不可靠**——它当时就是按"常识"写的，我重看一遍都能发现明显问题（比如 オルガ、ながえSTYLE 同时出现在有码和无码两类里，说明分类本身有逻辑错误）。

但好消息是：**你的数据里藏着比"常识"可靠得多的信号**——番号规则。有码和无码的发行渠道完全不同，番号格式是硬证据：

## 数据里能挖出的判断依据

1. **番号前缀格式**（最强信号）

   - 有码作品走日本内容审查机构，番号是"字母前缀-数字"（如 `MIZD-972`、`ABW-123`）

   - 无码片商面向海外发行，格式完全不同：1pondo 是纯数字日期式（`101921_001`）、HEYZO 是 `HEY-xxx`、加勒比系也是日期式——这些在 3668 条数据里一眼可辨
2. **BD/HD 后缀**：数据里存在 `LAF-82` 和 `LAFBD-82` 这种成对版本，BD 后缀版就是无码版（这是明确规律）
3. **按厂商聚合番号前缀**：同一厂商所有作品的番号前缀高度一致，把 3668 条按"厂商→前缀→条数"聚合，每个厂商的发行身份会自己浮现出来，比记厂商名录可靠

## 做不到的部分

有些情况光凭元数据分不清：厂商改名换马甲、集团内共用前缀、DMM 配信版与碟片版差异、"流出片"和官方无码版混在一起。这些没有画面内容就无法定论。

## 我的建议做法

不做"权威分类"，而是**规则自动打标 + 存疑留给你确认**：

1. 写个脚本扫 data/，输出"厂商 → 番号前缀 → 条数"对照表
2. 用上面的规则自动分类：纯数字日期式、HEY 前缀、带 BD/HD 成对版本的 → 标无码；其余默认有码
3. 规则覆盖不到的厂商列一份"待确认清单"给你过目，你说了算
4. 确认结果存成 JSON 接入筛选功能

这样得到的分类每一条都有数据依据，错了也容易定位。要按这个思路做的话我就先跑脚本，把分类结果和存疑清单给你看。

npm run works:all\
npm run works:covers         # 抓数据 + 下载封面（封面串行下载，更慢）
npm run works:covers-only    # 事后只补封面，不重抓数据
